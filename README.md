# 研星站 · 小学知识图谱（语文 / 数学 / 英语，1–6 年级，免费开源）

> **一句话：** 把小学 1–6 年级语文、数学、英语的校内知识点，按「由易到难 + 前后衔接」串成一张图谱。每个知识点都配有通俗讲解、易错点提示、掌握标准，还有一句给家长的「随口问一句」。**全部免费，开源可下载。**
>
> 目的：校内知识高效学透，省出时间。

**为什么做：** 对很多家庭来说，孩子的校内知识不一定要额外花钱去补。家长本来就在家陪孩子学，常常缺的只是一个方向：先抓什么，孩子可能卡在哪，这个点可以怎么讲。这份图谱想做的就是指个方向，所以它真心免费：不设付费墙，不需要注册，也不卖任何东西。它只是一份参考资料，替代不了学校老师，每个孩子的情况也不一样。

**关键词：** 小学知识点 · 知识图谱 · 前置知识 · 学习路线 · 人教版数学 · 统编版语文 · 译林版英语 · Super Minds · 一年级上册 · 易错点 · 掌握标准 · 家长辅导 · 怎么给孩子讲

- **免费：** 所有内容免费查看、下载，不设付费墙，不需要注册。
- **由易到难：** 主轴是难度和前置关系，不按年级切；同一主题跨年级串成「主题链」，比如 数的认识 → 加减 → 乘除 → 分数小数。
- **也能按校内进度查：** 每个知识点都标了对应的教材版本、年级、册和单元。
- **讲法统一：** 先用生活场景引入，再一句话讲透本质，配上口诀或类比、分步骤小台阶和最常见错误对照（见 [讲法规范](CONTRIBUTING/讲法规范.md)）。
- **不含教材原文：** 只列册、单元和知识点名称；讲解、例子和口诀全部是自己写的，不搬课文、例题和插图。

> 当前状态：**样板阶段（草稿，待教师审核）**。已有人教版数学一年级上册 14 个点、统编版语文 5 个点、英语（译林版三起 + Super Minds 第 2 版）5 个点，用来验证三科能共用同一套结构。

## 怎么用（4 步）

1. **按教材找到知识点**：打开 [按教材查](docs/按教材查.md)，找到孩子正在学的那一单元，点进对应的知识点。
2. **找卡点**：看页面里「学它之前要会的」这条前置链，用「家长随口问一句」从当前这个点往回问。哪一步孩子说不清，卡点大概就在那里。
3. **讲懂**：按页面的讲法跟孩子聊一遍：生活场景 → 一句话本质 → 口诀或类比 → 一步一步来 → 最常见的错。
4. **有方向地练**：讲懂之后，从家里已有的教辅或课本练习里，挑几道和这个知识点对应的题来练，不用另外买资料。练几道、什么时候练，看孩子的状态和学校的安排，不必另定任务。

知识点弄懂了、家长心里有数了，再有方向地练，通常比漫无目的地多做题更省力。不过每个孩子情况不同，这份图谱不承诺任何效果。

## 每个知识点有什么

| 部分 | 说明 |
|---|---|
| 一句话讲透 | 孩子能听懂的一句话本质 |
| 前置知识 | 学它之前要先会什么（分「必需」和「有帮助」），附一句原因 |
| 怎么讲 | ① 生活场景引入 ② 一句话本质 ③ 口诀或类比 ④ 分步骤小台阶 ⑤ 最常见错误对照 |
| 易错点提示 | 孩子最容易出错的地方 |
| 掌握标准 | 怎样算学会了，都是看得见的行为 |
| 家长随口问一句 | 家长不用会讲，问这一句就能看出孩子懂没懂 |
| 难度档 D1–D5 | 按前置深度定档，与年级无关（规则见讲法规范） |

## 给开发者 / 想接入 AI 的人

- 数据：`data/<学科>/<教材>/topics.json`（知识点）、`dependencies.json`（前置边）、`data/chains.json`（主题链）
- 结构说明：`schema/*.schema.json`
- 质检：`python3 scripts/validate.py`（检查重复、成环、前置倒序、难度倒挂、禁用词、讲解长度）；`python3 scripts/selftest.py` 用来确认校验器能拦住坏数据
- 生成页面：`python3 scripts/build_pages.py`
- 只用 Python 标准库，没有第三方依赖。
